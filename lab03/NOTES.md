# Отличия команд Git и поиск изменений

## 1. Отличия git diff, git show и git log

| Команда | Что показывает? | Основное назначение |
| :--- | :--- | :--- |
| **`git diff`** | Разницу между состояниями (между рабочим каталогом, индексом, коммитами или ветками). | Посмотреть незакоммиченные изменения или сравнить две разные точки в истории. |
| **`git show`** | Детальную информацию о конкретном объекте Git (чаще всего о конкретном коммите). | Посмотреть автора, дату, описание и полный патч (diff) одного конкретного коммита. |
| **`git log`** | Историю коммитов (список ревизий с их метаданными). | Проверить хронологию разработки, найти нужный коммит по автору, дате или сообщению. |

---

## 2. Что именно нашли команды log -S и blame?

* **`git log -S "строка"`** *(Pickaxe search)*:
  Ищет коммиты, в которых количество упоминаний заданной строки **изменилось** (строка была добавлена или полностью удалена). Она помогла найти точный момент в истории (коммит), когда в коде появилось или исчезло интересующее нас ключевое слово или функция.
  
* **`git blame`**:
  Показывает автора, хэш коммита и дату последнего изменения для **каждой отдельной строки** в указанном файле. Она помогла определить, кто именно и когда последним редактировал конкретную строчку кода, вызвавшую ошибку.
